# Droppr.

Droppr is a small, local-first web app for scheduling a song so a marked moment lands at a chosen time.

## How it works

1. Import an audio file.
2. Play the track and mark the exact drop point.
3. Choose when that moment should happen.
4. Enable playback and keep the tab open.

The app uses the Web Audio API for scheduled playback and stores songs and drops in the browser with IndexedDB. No audio is uploaded to a server.
